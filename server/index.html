ELKSLODGE

MicroWeb users are welcome at the ELKSLODGE.

A private local package shelf for ELKS on 8086 and 8088 computers. These programs are ELKS binaries, not DOS executables. MicroWeb can browse this page; use ELKS curl and the ELKSLODGE client to install packages.

Start here

Replace HOST with your local companion's address. In the ELKS shell:

export ELKSLODGE_SERVER=http://HOST:8086
curl -o /tmp/get http://HOST:8086/get
sh /tmp/get
elkslodge list
elkslodge install all

Existing client? Download upgrade to /tmp/lodgeup, then run sh /tmp/lodgeup. Keep power on during installation.

Packages

  • neofetch: compact native system information.
  • TPLAY: experimental Tandy PSG MIDI player. Original demo MIDI. Physical audio and timing not yet verified.
  • fortune and BOFH: quotes and excuses. The client installs their required data. Classic collections may contain dated language.
  • cowsay and cowthink: cow speech and thought bubbles.
  • elksay and elkthink: elk speech and thought bubbles.
elkslodge install elksay
fortune | elksay

Plain-text package list.

This shelf serves preloaded packages. The companion can fetch administrator-configured HTTPS artifacts, but no public upstream catalog is configured by default. htop is not included.

Source and rebuilding

Source for every package and the client is freely available in the ELKSLODGE repository. Use a modern HTTPS-capable computer for that link, then transfer the files locally. Build commands and all application sources are included there.

The native programs link ELKS libc. Its complete matching ELKS 0.9.2 source and build instructions are available for rebuilding and relinking.
